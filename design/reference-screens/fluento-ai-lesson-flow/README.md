# Fluento AI — Restored lesson flow

Thư mục này là bản khôi phục của lesson-flow design:

- design.html: prototype HTML/CSS/JavaScript tương tác với 20 màn product.
- Ảnh 01–20: visual reference cho từng màn.
- source-variants/: 10 màn cũ từ fluento-ai-v1.
- assets/generated/: illustration, icon UI trong suốt và background surfaces.

Prototype chạy theo luồng:

Onboarding → Home → Create lesson → Lesson ready → Theory overview → Grammar/Vocabulary/Writing → Exercises → AI feedback → Library/Profile

Các màn HTML dùng data-go, data-chip và data-tab làm contract để chuyển sang SwiftUI, React Native hoặc Flutter.
