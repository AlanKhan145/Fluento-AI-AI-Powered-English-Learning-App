# Fluento AI — AI-Powered English Learning App

**Fluento AI** is a mobile English-learning application that allows users to create personalized lessons with artificial intelligence.

Inspired by the simplicity of AI content-generation platforms, Fluento turns a short learning request into a complete English lesson containing both **theory and interactive exercises**. Instead of following a fixed curriculum, users can simply describe what they want to study, such as:

> “English for ordering food at a restaurant”

or

> “Practice B2 phrasal verbs for job interviews”

The AI then generates a structured lesson based on the selected topic, language level, lesson type, and exercise preferences.

## Core Features

Users can customize each lesson by choosing:

* English proficiency level from **A1 to C2**
* Lesson type such as **Grammar, Conversation, Reading, Vocabulary, or Exam Practice**
* Number of questions
* Types of exercises
* Whether to include theory and answer explanations

Fluento supports multiple interactive exercise formats, including:

* **Multiple Choice** — four-option questions
* **True / False**
* **Short Answer**
* **Complete the Paragraph**
* **Writing Tasks**
* AI-generated explanations and answer keys

For writing exercises, an LLM evaluates the user's response and provides detailed feedback, including:

* Grammar
* Vocabulary
* Coherence
* Task response
* Overall score
* Corrections and improvement suggestions
* Model answers

## AI-Generated Learning Experience

The main goal of Fluento is to make English learning highly personalized. Instead of searching for the right lesson, users can **generate exactly what they want to learn**.

The AI acts as both a **lesson creator and personal tutor**, generating learning materials, checking answers, explaining mistakes, and adapting practice content to the learner's needs.

## Design Concept

Fluento uses a modern, dark mobile interface with colorful gradient accents, large typography, rounded cards, and a content-first layout.

The design focuses on making AI lesson creation feel fast and creative while keeping the learning experience simple and structured.

The main navigation includes:

**Home · Explore · Create · Practice · Profile**

The central **Create** action allows users to generate a new English lesson at any time.

## Project Goal

Fluento explores how generative AI can transform traditional language-learning applications from static course platforms into **dynamic learning systems where every lesson can be generated on demand for each individual learner**.
